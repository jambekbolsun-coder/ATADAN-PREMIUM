# ATADAN Changfa

Полноценный сайт-каталог официального дистрибьютора тракторов Changfa: 41 модель от 50 до 240 л.с., страницы техники, форма заявки с переходом в WhatsApp, рассрочка, сервисные страницы и защищённая CRM-админка.

## Возможности

- каталог с поиском, фильтрами по мощности и наличию;
- отдельная SEO-страница каждой модели с характеристиками и scroll-анимацией;
- заявки сохраняются в базе и открывают подготовленное сообщение в WhatsApp;
- админка: сводка, товары, заявки, аналитика интереса, профиль;
- адаптивный интерфейс для телефона, планшета и десктопа;
- данные и фотографии моделей собраны с официального сайта Changfa.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Локально сайт откроется на `http://localhost:3000`. Админка находится по адресу `/admin`. Для локального предпросмотра используется пароль `atadan-preview`; на опубликованном сайте пароль задаётся переменной `ADMIN_PASSWORD`.

## Проверка

```bash
npm run lint
npm test
```

## Переменные окружения

Скопируйте `.env.example` в `.env.local` и укажите безопасный пароль администратора. Файл `.env.local` не добавляется в Git.
