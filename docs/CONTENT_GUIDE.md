# Руководство по контенту

## Правило фактов

1. Цена публикуется только при наличии актуального коммерческого подтверждения.
2. Комплектационные параметры сопровождаются фразой «зависит от комплектации».
3. Общая техническая информация берётся из заводского каталога.
4. Коммерческая комплектация и условия сделки берутся из материалов ATADAN.
5. При расхождении оба источника сохраняются, а финальное значение подтверждает менеджер.

## Стиль текста

- короткие предложения;
- сначала термин, потом простое объяснение;
- практическая польза вместо рекламных общих слов;
- не обещать банковское одобрение;
- не называть демонстрационный цвет складским.

## Обновление модели

Измените объект в `frontend/src/data/tractors.js` и seed в `backend/app/services/seed.py`. Для новых цен добавьте источник и дату подтверждения.
