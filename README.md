# ATADAN Changfa

Полноценный сайт-каталог официального дистрибьютора тракторов Changfa: 41 модель от 50 до 240 л.с., страницы техники, форма заявки с переходом в WhatsApp, рассрочка, сервисные страницы и защищённая CRM-админка.

## Возможности

- каталог с поиском, фильтрами по мощности и наличию;
- отдельная SEO-страница каждой модели с характеристиками и scroll-анимацией;
- заявки сохраняются в базе и открывают подготовленное сообщение в WhatsApp;
- админка: сводка, товары, заявки, аналитика интереса, профиль;
- ATADAN АгроЖурнал: 12 готовых материалов на русском, кыргызском и английском, поиск, категории и связанные модели;
- редакция в админке: черновики, публикация, архив, языковые версии, обложки, галереи и статистика просмотров;
- адаптивный интерфейс для телефона, планшета и десктопа;
- данные и фотографии моделей собраны с официального сайта Changfa.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Локально сайт откроется на `http://localhost:3000`. Админка находится по адресу `/admin`. Для локального предпросмотра используется логин `atadan` и пароль `atadan-preview`. На опубликованном сайте несколько администраторов задаются секретной переменной `ADMIN_USERS_JSON`: пароли хранятся только как PBKDF2-SHA256 хеши. Подпись восьмичасовой HttpOnly-сессии задаётся отдельным секретом `ADMIN_SESSION_SECRET`.

## Проверка

```bash

```

## Переменные окружения

Скопируйте `.env.example` в `.env.local` и укажите безопасный пароль администратора. Файл `.env.local` не добавляется в Git.
