# Архитектура

## Frontend

SPA на React/Vite с реальными URL-маршрутами через React Router. Данные каталога находятся в `frontend/src/data`, а пользовательские предпочтения сравнения и избранного сохраняются в `localStorage` через Zustand.

Основные слои:

- `pages` — маршруты и крупные сценарии;
- `components` — карточки, формы, калькулятор, таблицы и навигация;
- `data` — модели, серии, статьи, запчасти и справочные материалы;
- `i18n` — четыре JSON-словаря;
- `services` — взаимодействие с FastAPI;
- `styles` — единая адаптивная дизайн-система.

## Backend

FastAPI предоставляет:

- каталог тракторов;
- карточку модели;
- приём лидов;
- приём сервисных заявок;
- health-check.

SQLAlchemy использует SQLite по умолчанию. Для PostgreSQL достаточно изменить `DATABASE_URL` и установить драйвер.

## Данные

Коммерческие характеристики из PDF сохранены в frontend и seed backend. Неподтверждённые данные не превращаются в факты: интерфейс показывает уточняющие примечания.
