# Переводы

Поддерживаются:

- `ru` — русский, язык по умолчанию;
- `ky` — кыргызский;
- `en` — английский;
- `zh-CN` — упрощённый китайский.

UI-словари: `frontend/src/i18n/locales/`.

Динамические тексты моделей хранятся объектами `{ru, ky, en, zh-CN}` в `tractors.js`. Технические названия моделей не переводятся.

При добавлении ключа:

1. Добавьте его во все четыре JSON-файла.
2. Проверьте selector языка.
3. Не используйте машинный дословный перевод сложных терминов без проверки специалистом.
4. Кыргызский текст делайте простым и разговорно-понятным.
5. Китайский — только упрощённые иероглифы.
