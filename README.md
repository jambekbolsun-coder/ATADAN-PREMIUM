# ATADAN Changfa

Многостраничный каталог и SQL-CRM официального дистрибьютора Changfa в Кыргызстане. В каталоге 41 модель от 50 до 240 ЛС, отдельные страницы техники, лизинговый калькулятор, сервис, контакты и АгроЖурнал с 12 готовыми публикациями.

## Что входит

- каталог с поиском, фильтрами, наличием, акциями, рекомендациями и популярными моделями;
- карточка каждой модели: галерея, характеристики, комплектация, комфорт, видео для тяжёлой линейки и расчёт лизинга до 84 месяцев;
- заявки одновременно сохраняются в SQL как обращение, клиент и сделка, затем открывают подготовленный диалог WhatsApp;
- SQL-CRM: этапы продаж, клиенты, задачи, заметки, ответственные менеджеры, себестоимость, маржа и журнал действий;
- роли `owner` и `manager` с серверным разграничением данных;
- одноразовые приглашения менеджеров с QR-кодом, сроком 24 часа и самостоятельной установкой пароля;
- управление товарами, публикациями, контактами, условиями лизинга и персональной темой кабинета;
- аналитика интереса к моделям и публикациям;
- адаптивный интерфейс для телефона, планшета и десктопа.

## База данных

Вся админка и CRM работают на SQL-базе SQLite/D1 через binding `DB`. Схема находится в `db/schema.ts`, а версионные миграции — в `drizzle/`. Приложение никогда не создаёт и не изменяет таблицы во время обычного запроса.

Подробная архитектура, таблицы, права и порядок миграций описаны в [docs/SQL-CRM.md](docs/SQL-CRM.md).

## Локальный запуск

Нужен Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Сайт: `http://localhost:3000`. Админка: `http://localhost:3000/admin`.

Для локального предпросмотра допускается `atadan / atadan-preview`. На опубликованном сайте исходная учётная запись задаётся хешированным `ADMIN_USERS_JSON`. После первого успешного входа пароль переносится в SQL в виде PBKDF2-SHA256-хеша, а дальнейшие сессии хранятся в `staff_sessions`.

## Проверка

```bash
npx tsc --noEmit
npm run lint
npm test
```

Секреты и реальные пароли не должны попадать в Git, клиентский JavaScript или документацию.
