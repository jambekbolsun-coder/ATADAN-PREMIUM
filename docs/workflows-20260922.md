# ATADAN: изменения рабочих сценариев

## Публичный сайт

- Подбор: два вопроса, четыре диапазона мощности, семь областей и города Бишкек/Ош. Выбранный регион сохраняется с заявкой и событиями просмотра при согласии на аналитику.
- Лизинг: фиксированные 84 месяца (7 лет), ползунок взноса, корректный итог с первоначальным взносом. При отсутствии опубликованной цены клиент вводит ориентировочную стоимость. В CRM она отмечается `priceSource: customer_estimate`. Ставки и комиссии берутся из настроек.
- Карточки моделей: заявка с моделью, видео перед характеристиками. Отправка сохраняет заявку и показывает подтверждение. WhatsApp открывается только по отдельной кнопке после сохранения.
- Телефоны Кыргызстана, России, Казахстана, Узбекистана и Таджикистана. Код Кыргызстана выбран изначально.
- Пять новых FAQ; три исходных вопроса также доступны для редактирования. Панель прокручивается.

## Администратор

- Этапы «Встреча назначена» и «Встреча проведена» создают/обновляют связанную встречу. Повторные переходы не дублируют запись. Изменение сделки и встречи выполняется транзакционно. Последующие задачи создаются по этапам.
- Поставки: компания и её телефон, водитель и его телефон, даты, груз, описание, внутренние/внешние, отчёты файлами. Заказ поставщику необязателен.
- Документы: три переименовываемые папки, карточки, текущая дата, первичный/импорт 40/импорт 70, собственные типы, несколько файлов. Связи с CRM, договором и лизинговым пакетом доступны в сворачиваемом блоке.
- Сервис: компания, гарантийный/негарантийный случай, клиент, телефон, дата, моточасы, модель со склада с группировкой по категории. Если VIN ещё не заведен, можно выбрать модель каталога без создания фиктивной складской единицы.
- Расходы: название, описание, категория, дата, получатель, сумма, чек. Категории расширяемые. Проведённые финансовые записи защищены от прямого редактирования.
- Чистая прибыль учитывает себестоимость проданной техники и зарегистрированные расходы. Сторно оплаты не считается расходом компании.
- Убраны пункты счетов/кассы, рисков склада, менеджеров и прогноза. Учётные связи в базе сохранены. Раздел помощника не менялся.
- Чат: личные диалоги, группы, текст, изображения, документы, аудио; запись голоса, предпрослушивание, повторная отправка без дубля. Обновление открытого раздела каждые 5 секунд. Старые рабочие группы переносятся с участниками.
- Новые вложения защищены авторизацией; вложения чатов доступны отправителю и участникам разговора. Один файл до 4 МБ, до 8 вложений в сообщении, запись до 3 минут.
- Уведомления: отступы, адаптивные кнопки, категории, читаемые приоритеты, обработка ошибок.

## Хранилище и миграции

Публичные изображения используют прежний `BLOB_READ_WRITE_TOKEN`. Внутренние файлы используют отдельный **private** store и `ATADAN_PRIVATE_READ_WRITE_TOKEN`. Оба токена задаются только через окружение; токен закрытого хранилища уже подключён к проекту Vercel.

Миграции в `db/admin-v2-schema.ts` добавочные и идемпотентные. Исходные записи, история и финансовые связи сохраняются. Новые данные региона не восстанавливают географию прошлых посещений.

## Проверка

`npm test`: сборка и 32 теста. `npm run lint`: ESLint. Сквозные проверки проводятся в отдельной схеме PostgreSQL с тремя тестовыми сотрудниками.

- `scripts/workflow-e2e.mjs`: 14 сценариев новых рабочих процессов.
- `scripts/verify-admin-e2e.mjs`: полный путь от заявки до оплаты, продажи и сервиса, права, импорт/экспорт и целостность резервной копии.
- `scripts/upload-e2e.mjs`: реальные загрузки и проверка доступа.
- `scripts/concurrency-workflows.mjs`: конкурентная отправка заявок и сообщений, параллельное чтение, отрицательные проверки файлов и прав.
- `scripts/browser-workflows.mjs`: квиз, заявки, калькулятор, документы, мобильные экраны и настоящая запись тестового аудио через MediaRecorder.
- `scripts/recovery-workflows.mjs`: перенос старых групп, сохранение введённых данных при обрыве сети, повторное сохранение, мобильные уведомления.
- `scripts/service-model-workflows.mjs`: сервис с VIN и без него, категории моделей, отклонение неизвестной модели.

Для нового изолированного прогона нужен настроенный `.env.local`, `ATADAN_ISOLATED_TESTS=1` и запуск `node --experimental-strip-types scripts/setup-workflow-test.mjs`. Он создаёт отдельную схему, сохраняет исходное окружение вне репозитория и переключает локальное подключение. Повторное создание при существующем контексте запрещено. Для браузерных сценариев нужен Playwright: установленный пакет либо `PLAYWRIGHT_MODULE` с URL модуля. Сервер тестов запускается на порту 3022. Тестовые схемы, сессии и вложения после проверки удаляются; этот контекст не отправляется на Vercel.

## Данные, которые должен подтвердить владелец

В каталоге пока нет опубликованных цен всех 41 моделей. Для точного расчёта нужно заполнить цены и проверить фактические ставки/комиссии. До этого клиенту доступен явно обозначенный предварительный расчёт по введённой стоимости.
