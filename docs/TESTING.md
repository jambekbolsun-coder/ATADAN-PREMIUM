# Тестирование

## Frontend unit

`npm run test`

Проверяется:

- наличие семи коммерческих моделей;
- подтверждённая цена CFJ220;
- работа формулы лизинга.

## E2E

`npm run build && npm run test:e2e`

Проверяется:

- главная;
- каталог;
- страница CFJ220;
- переключение языка;
- desktop и mobile viewport.

## Backend

`python -m pytest`

Проверяется health-check, каталог и сохранение лида.

## Ручной QA-чеклист

- все 25 маршрутов открываются;
- нет горизонтального скролла на 360 px;
- изображения без интерфейса телефона;
- WhatsApp использует номер +996 706 131 404;
- цена есть только у CFJ220;
- 404 работает;
- формы показывают fallback на WhatsApp при недоступном API;
- selector языка сохраняется в localStorage.
